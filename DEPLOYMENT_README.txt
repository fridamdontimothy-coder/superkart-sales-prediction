SuperKart Streamlit deployment
===============================
Files required together: app.py, requirements.txt, superkart_model.joblib, superkart_metadata.json.
Local launch: pip install -r requirements.txt && streamlit run app.py
Cloud launch: create a GitHub repository with these four files, then deploy app.py via https://share.streamlit.io/ .
For submission: visit the live app; take authentic screenshots of (1) a single prediction with the browser URL visible and (2) batch upload and prediction output; insert them in slides 11 and 12 of the PPTX; export the updated PPTX to PDF. Submit ONLY the final PDF.
Important: no quarterly date series is available, so forecast validity for next quarter is not established. Product category labels in supplied batch are retained as provided; training category grouping is a documented assumption. Store age uses reference year 2025.
